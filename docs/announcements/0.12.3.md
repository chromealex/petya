# Кто из команды — вы

- В «Команде» у каждой карточки есть галочка «Это я», рядом с именем — отметка «это вы». Без отметки Петя сам найдёт вашу карточку по email из Jira или по полному имени.
- В ответах Петя говорит вам «ты» и больше не пишет «Алекс (или ты)», когда Алекс — это вы.
- Полосы прокрутки везде одинаковые — тонкие, как в чате, в том числе в окне дашборда.
- В настройках «Модели Пети» видна версия группы моделей, для каждой части можно выбрать опубликованную версию и модель для ответов по умолчанию.
