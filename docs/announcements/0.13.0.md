# Генератор уровней для RTS-движка

- Новое приложение «Генератор уровней» в разделе «Геймдев»: скажите «сгенерируй карту 2 на 2 с рекой посередине» или «сделай симметричную карту для 4 игроков, побольше руды» — Петя сделает карту движком RTS через его rtsmcp, проверит её и покажет картинку со стартами, месторождениями и длиной пути между базами.
- Карту можно править словами: «сделай реку шире», «добавь ещё 2 месторождения у центра», «больше руды» — и откатить кнопкой «Отменить правку». «Ещё вариант» пробует следующий сид.
- «Проверить баланс» прогоняет матчи ботов: сколько побед у каждого старта и сколько длится матч.
- В проект карта попадает только по кнопке «Сохранить в проект» и после подтверждения; существующую карту Петя без второго «Перезаписать» не трогает. «Открыть в редакторе» запускает редактор движка с проектом.
- Если движок уже установлен (PATH, ~/RTSEngine или папка в настройках), Петя берёт его. Иначе скачает готовую сборку (Mac на Apple Silicon — около 43 МБ, Windows — около 53 МБ), проверит контрольную сумму и предложит «Обновить», когда выйдет новая.
