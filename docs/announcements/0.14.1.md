# Петя для Mac, генератор уровней и 12 новых приложений

- **Петя для Mac**: в релизах теперь есть `Petya.dmg` для Mac на Apple Silicon — подписан и проверен Apple, открывается без предупреждений. Откройте и перетащите Петю в «Программы».
- **Генератор уровней**: RTS-карты по фразе — «сгенерируй карту 2 на 2 с рекой посередине»; правки словами, проверка баланса матчами ботов, сохранение в проект.
- **Команда**: онбординг новичка, найм (кандидаты, вопросы, отзывы интервьюеров), материалы для перформанс-ревью.
- **Документы**: GDD с цифрами из конфигов, вики из обсуждений, сравнение версий документа, разбор договоров в PDF.
- **Компьютер**: запись экрана сразу в баг, история буфера обмена, разбор папки загрузок.
- **Геймдев**: симуляция экономики и прогрессии, идеи ивентов к праздникам.
- В настройках Grafana подсказка, откуда взять токен.
