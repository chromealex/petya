# Темы оформления, страницы приложений и дашборды из одной фразы

- **Оформление**: светлая, тёмная или как в системе; заготовки «Лес», «Графит», «Океан», «Закат», «Снег», «Бумага», «Мята», свой акцентный цвет и размер текста. Настройки → «Приложение» → «Оформление».
- **Свои страницы у приложений**: приложение может добавить пункт в меню слева и вкладки на страницах Пети. Напоминания теперь живут в приложении «Напоминания», ничего не потерялось.
- **«Собери дашборд: основные метрики (из wombyte), краши и ANR»**: Петя сам добавляет нужные приложения, берёт метрики из вашей Grafana, а для того, чего нет ни в одном приложении, просит ссылку на страницу и показывает её как виджет.
- **Google Play** объясняет, почему не пускает: не включён API в Google Cloud (со ссылкой) или нет доступа в Play Console.
- После входа через браузер (Gmail, Outlook, Google Play) — страница в стиле Пети, которая закрывается сама.
- «Развитие» переехало вниз боковой панели.
