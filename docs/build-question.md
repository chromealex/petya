# «Петя, что с билдом»

Эта команда означает запросить статус у людей в Slack, а не только пересказать сохранённый лог. Поддерживаются «что с билдом», «что с билдом 123», «как там сборка». Если в той же фразе сказано «не пиши», «не отправляй», «без отправки», отправки нет.

Контекст берётся из активной темы со ссылкой на Slack-тред; иначе — из сохранённых обсуждений сборок за последние сутки, с учётом известного проекта и указанного номера. Несколько подходящих обсуждений требуют выбора. Содержимое треда перечитывается через Slack API до отправки. Неполная загрузка, смена темы/аккаунта во время выбора или несколько номеров без уточнения останавливают отправку.

Ответственный определяется по свежим сообщениям текущего треда: автор «собираю билд», «запустил сборку», либо единственное упоминание пользователя в сообщении с явной ответственностью за сборку. Учитываются номер билда, возраст сообщения и отрицания. QA не выбирается только по должности. Если ответственность указана без Slack-идентификатора или фраза не распознана, получатель не выдумывается. Несколько найденных ответственных предлагаются кнопками/номерами/точным отображаемым именем; можно выбрать «в общий чат». Перед личным сообщением аккаунт проверяется через users.info.

Если персональный ответственный не установлен, вопрос отправляется новым сообщением в канал текущего обсуждения. Это может быть публичный или приватный рабочий канал, но не произвольный #general. В личной переписке без установленного ответственного требуется уточнение.

Петя отправляет только фиксированный короткий вопрос: какой сейчас статус сборки, готова ли она или есть блокер, плюс ссылка на обсуждение. Логи и инструкции из сообщений не пересылаются. Личные сообщения отправляются через conversations.open; для общего канала создаётся отдельный вопрос с собственным тредом. Подтверждение перед однозначной отправкой не требуется — это действие явно задано командой пользователя.

Петя проверяет ответы в треде отправленного вопроса раз в минуту (общая очередь для нескольких вопросов). В личном сообщении учитывается ответ выбранного адресата, в канале — другого человека. Ответ цитируется в сохранённой теме и приходит уведомлением. Сообщения вне треда вопроса не отслеживаются. Полностью закрытый Петя не получает ответы; при следующем запуске проверка продолжается в пределах суток. Нет автоматических повторных напоминаний коллегам.

Повтор команды в течение 15 минут возвращает уже отправленный вопрос/полученный ответ. Журнал сохраняется зашифрованно. Если доставка не подтверждена из-за сетевого сбоя, автоматической повторной отправки нет, в том числе после перезапуска; нужно проверить Slack вручную. Такие записи блокируют повтор до удаления по общему сроку памяти. При выключении Slack опрос прекращается. «Очистить память» удаляет локальный журнал, но не удаляет сообщения из Slack.

Права User Token: chat:write, im:write, users:read плюс существующие права чтения каналов/тредов. Новые scopes добавлены в исходники OAuth-сервера. Уже развёрнутый OAuth-сервер этим не обновляется: его нужно обновить и переподключить Slack; при ручном токене добавить права и переустановить Slack-приложение в workspace. Ошибка missing_scope показывается пользователю, отправка не объявляется успешной.

Автоматические тесты используют имитацию Slack и не отправляют настоящих сообщений. Живой сценарий зависит от выданных прав и наличия доступного обсуждения.
