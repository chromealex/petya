# Learning unknown formats

When it encounters an unknown extension, Petya searches Google for the format specification and ways to read it, reads up to three of the pages found, and asks the local Ollama model to prepare a handler. The search query contains only the extension, without the file name or its contents. A sample of the bytes is passed only to the local model. Cloud models are prohibited for this scenario.

The handler runs in a separate sandboxed Electron renderer, without Node, preload, network, dialogs or file system access. It receives only the bytes of the selected file and verified text members of ZIP/GZIP archives. It cannot download libraries or install programs. Run time is up to 15 seconds; the result is up to 40 000 characters. The 10 MB limit still applies to unknown documents; the absence of a size limit for video applies to the separate streaming video decoder.

The handler code is prepared from the documentation that was read, verified by running it on the file, and saved only after it produces a non-empty text result. This does not prove that every variant of the format is parsed correctly: version, encryption, packaging or vendor-specific details may differ. If a saved handler stops reading a file, it is deleted and a reading method is searched for again. If the new code fails, one fix attempt is allowed. If a password, an external program or an unavailable library is needed, Petya says so and suggests exporting; content is never made up.

Reading methods and documentation links are stored encrypted in file-formats.json of the current company, work after a restart and without rebuilding. The key consists of the extension and the container type. In the «Обучение новым форматам файлов» (Learning new file formats) section next to attachments you can view the sources and forget a method.

If search is turned off, Petya offers to turn it on. After a CAPTCHA or an error, the «Продолжить чтение файла» (Continue reading file) button retries with the file held in memory (up to 30 minutes). Cancelling deletes the pending file; clearing the context or switching company cancels the current learning. Learned methods are kept until explicitly deleted. To select an arbitrary file in the system dialog, there is an «Все форматы» (All formats) filter. Files with unknown extensions from selected Telegram/Slack chats go through the same path.

Isolation relies on the [Electron sandbox](https://www.electronjs.org/docs/latest/tutorial/security) and request blocking via [WebRequest](https://www.electronjs.org/docs/latest/api/web-request). Tests verify an actual run of a new handler, the network and Node ban, stopping hung code, saving, and reuse without searching. External sites and the quality of generated handlers depend on the documentation and the installed local model.
