# Обучение проверке Gmail

В «Подключениях» включите Gmail. Для первого входа требуется собственный OAuth-клиент Google типа **Desktop app**: включите Gmail API, настройте экран согласия, добавьте свой аккаунт в Test users (если приложение в Testing), скачайте JSON клиента и импортируйте его в карточке Gmail. Затем нажмите «Войти через Google». Пароль вводится только на сайте Google. Внешнее приложение в Testing может требовать повторного входа через 7 дней.

Скажите «Научись проверять почту». Опишите период, непрочитанные/все письма, исключение рассылок, приоритетных отправителей и правила пересказа. Петя покажет получившиеся параметры. «Попробуй» читает реальную почту; затем можно уточнить правила и повторить проверку. «Сохрани навык» сохраняет проверенный вариант. «Отмени обучение» отменяет черновик. В разделе «Обучение → Почтовые навыки» доступны ручное редактирование, проверка, отключение и удаление, а также сохранение без проверки. Перезапуск и пересборка не нужны.

Это первый поддерживаемый составной навык: чтение Gmail → фильтрация → пересказ. Инструменты фиксированы в приложении, правила и фразы — пользовательские. Обучение не устанавливает новые интеграции и не исполняет произвольный код. Для других сервисов нужны отдельные инструменты.

Точные фразы работают без модели. Правила из разговорного текста, похожие просьбы о почте и пересказ обрабатывает локальная Ollama. При ошибке пересказа выводятся фрагменты найденных писем. За запуск проверяется максимум 20 входящих писем; при наличии следующей страницы результат явно обозначается как выборка. Для пересказа берётся до 1500 символов текстовой части письма (для HTML-only — snippet). Вложения не читаются. Пропуск рассылок исключает категории promotions/social и письма с заголовком List-Unsubscribe; это технический фильтр, не безошибочный классификатор рассылок.

OAuth использует PKCE S256, случайный state и временный loopback listener на 127.0.0.1. Запрашивается только gmail.readonly. Токены и клиент сохраняются через шифрование ОС; они не доступны renderer. Отключение удаляет токены на устройстве, сохраняя настройку клиента. Отзыв разрешения у Google выполняется в аккаунте Google. Внешний интерпретатор Claude/Codex не получает историю темы, содержащую результаты почтового навыка.

Проверки: тестовый OAuth callback, неверный state, обновление токена, отключение, чтение только через GET, обучение/пробный запуск/сохранение/перезапуск/отмена, UI smoke. Реальный вход и чтение аккаунта требуют авторизации владельца и не заменяются этими тестами.

## Несколько аккаунтов

В карточке Gmail кнопка «Добавить аккаунт Google» подключает очередной ящик, сохраняя остальные. Адрес определяется через Gmail profile; повторный вход обновляет существующее подключение. Каждому ящику можно дать имя («Рабочая», «Личная») и отключить его отдельно. Импорт другого OAuth-клиента меняет настройку для новых входов, сохраняя клиент и токены ранее подключённых ящиков.

В редакторе навыка отметьте один или несколько аккаунтов либо включите «Все подключённые аккаунты, включая добавленные позже». Без выбора используется только единственный подключённый аккаунт; при нескольких требуется уточнение. В диалоге обучения доступны отдельные реплики «аккаунт Рабочая», «аккаунты work@gmail.com, personal@gmail.com», «все аккаунты». Названия должны быть уникальными; при совпадении укажите адрес.

Результат разбит по ящикам, лимит — 20 писем на ящик. Ошибка одного подключения показывается рядом с его адресом; остальные результаты сохраняются. Отключённый аккаунт в сохранённом навыке не заменяется другим автоматически. Ранее сохранённый одиночный вход переносится без удаления токенов; адрес определяется при первой проверке.
