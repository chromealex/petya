# Генерация изображений

В исходниках добавлены команды «Нарисуй кота-космонавта», «Сгенерируй изображение: лес на рассвете», «Создай иллюстрацию …». Результат показывается в чате и сохраняется кнопкой «Сохранить PNG» через системный диалог. Кнопка «Остановить генерацию» прерывает процесс; отмена во время перевода не запускает модель.

Локальный вариант: SD-Turbo, PNG 512×512, два шага. Русское описание переводит выбранная локальная модель Ollama. Генератор запускается отдельным процессом, после завершения освобождает память. Веса читаются только с диска (`HF_HUB_OFFLINE`, `local_files_only`), используются safetensors. Первая установка требует интернета и не менее 6 ГБ свободного места:

```sh
python3.10 scripts/setup-images.py
```

В интерфейсе: **Настройки → Сервисы → Генерация изображений → Установить**. Загрузка начинается только по кнопке. Доступны этапы установки, остановка и повтор после ошибки. До загрузки проверяются свободное место и наличие Python 3.10–3.12. Если подходящий Python не найден, карточка предлагает установить его. Готовность отмечается только после проверки загрузки модели.

Поддерживаются Apple MPS, NVIDIA CUDA либо CPU. Кнопка сохраняет окружение и веса в `image-generator/runtime` внутри пользовательского каталога Пети, общего для компаний. Они сохраняются при обновлении приложения. CLI использует `runtime/images` и `runtime/models/sd-turbo` рядом с исходниками. В установщик приложения веса не включены. Созданные картинки хранятся внутри зашифрованной истории чата и удаляются вместе с ней по существующему сроку хранения. Экспортированные пользователем PNG остаются на диске. Редактирование вложенных изображений пока не реализовано.

Основа интеграции: [официальная карточка SD-Turbo](https://huggingface.co/stabilityai/sd-turbo). Модель ограничена в воспроизведении текста и мелких деталей; условия коммерческого использования указаны в карточке модели.

## Проверка 4 ноября 2026

Пройдены модульные проверки маршрутизации, протокола процесса, ошибок, отмены, параллельных запросов и таймаута; регрессии списка возможностей и истории чата. Настоящая генерация ещё не проверена: первоначальная установка зависимостей остановилась из-за нехватки диска на Mac. Проверены установщик с имитацией процесса (место, Python, этапы, отмена, повтор, ошибки) и настоящее окно Electron (карточка, кнопка, прогресс, отмена, подсказка в чате). Во время этих проверок модель не скачивалась.

По просьбе владельца проверен вариант сервера RUVDS 194.87.110.60: 1 vCPU, 870 МиБ RAM, 1 ГБ swap, 14 ГБ свободного диска, GPU нет; petya-auth работает. Генератор на сервер не устанавливался: ресурсов недостаточно для выбранного Python/SD-Turbo runtime рядом с действующей авторизацией. Требуется выбор увеличения ресурсов или отдельного сервера. Сетевой клиент генерации ещё не подключён.

Владелец выбрал локальный вариант на Mac с необязательной установкой кнопкой в подключениях. Серверный вариант отложен.
