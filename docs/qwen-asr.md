# Qwen3-ASR в Пете

Движок для Apple Silicon: `mlx-qwen3-asr==0.4.4`, Qwen3-ASR 1.7B в 8-битном формате MLX. Закреплённые зависимости: `scripts/qwen-asr-requirements.txt`. Конвертированная модель: https://huggingface.co/mlx-community/Qwen3-ASR-1.7B-8bit , ревизия `a8379a2e2f9e313c9292cdf1af4055ab56d50d55`. Движок: https://github.com/moona3k/mlx-qwen3-asr . Исходная модель: https://huggingface.co/Qwen/Qwen3-ASR-1.7B .

Установка на Mac с Apple Silicon и Python 3.10+: `python3 scripts/setup-qwen-asr.py`. Окружение находится в `runtime/asr`, модель — `runtime/models/qwen3-asr-1.7b`. Маркер READY создаётся после успешной загрузки модели. Установка лежит рядом с приложением; перенос одного Petya.app не переносит Python и веса.

Если локальная установка готова, голосовой ввод выбирает Qwen; иначе остаётся прежний Whisper. Ошибки уже выбранного Qwen показываются явно, без скрытого переключения на другую модель. В индикаторе микрофона указан действующий движок. Озвучивание ответа от этого выбора не меняется.

Модель живёт в одном дочернем процессе. WAV передаётся через stdin в памяти, на диск голосовые команды не записываются. Рабочий процесс запускается с HF_HUB_OFFLINE=1. У каждого запроса свой ID, завершение процесса и тайм-аут освобождают ожидания. На этом этапе используется распознавание накопленных фрагментов после пауз; нативный streaming API Qwen ещё не подключён.

Проверки: `node tests/qwen-speech.cjs`; интеграционные проверки поля ввода — `tests/current-question-ui.cjs` и общий Electron smoke. Отправленный текст остаётся в истории, поле очищается; новый набираемый черновик сохраняется, при ошибке пустое поле восстанавливает запрос.

Локальный прогон 2026-11-04: синтезированные фразы «Петя, ты тут?» (1,787 с, пунктуация — точка), «Какие проекты у тебя есть?» (0,235 с) и английская фраза (0,332 с) распознаны без потери слов. Первая фраза включает первый вызов модели; следующие — прогретый процесс. Тишина и тихий случайный шум дали пустой текст. Результаты: `docs/qwen-asr-results.json`. Это время самого распознавания, без ожидания паузы и ответа помощника. Синтетические записи не заменяют проверку живой речи через микрофон.
