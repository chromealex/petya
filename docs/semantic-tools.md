# Понимание новых формулировок

Петя использует готовую локальную модель Ollama для выбора инструмента по смыслу запроса. Нейросеть не дообучается: ей передаются описание инструментов, текущая компания, последние четыре реплики активной темы и названия настроенных почтовых навыков. Секреты и настройки других компаний не передаются. Облачные модели для этого маршрутизатора отклоняются.

Знакомые команды, уточнения, обученные фразы и действия создания задач обрабатываются прежними механизмами. Для остальных запросов модель выбирает чтение багов Jira, ANR Google Play, Gmail по существующему навыку, поиск публичной информации, сводку, обычный диалог или уточнение. Свободный код, запись в сервисы и произвольные команды ОС не входят в этот каталог. Интеграции проверяются существующим кодом; не подключённый сервис предлагается подключить либо прочитать через встроенный браузер. Поисковый запрос берётся из текущей фразы, без добавления истории компанией моделью.

Невалидный ответ модели не запускает новый инструмент. Если Ollama недоступна, остаётся прежняя обработка; ошибка получения ответа показывается пользователю. Уверенность модели не является гарантией правильного выбора. Понимание не добавляет отсутствующие инструменты: новый сервис всё ещё требует реализации или доступного браузерного чтения.

В «Подключения → Ollama» можно отключить «Понимать новые формулировки через модель» или подготовить Qwen3.5:9B. Текущая модель заменяется только после успешной загрузки и проверочного ответа. Кнопка отмены сохраняет предыдущую выбранную модель. На небольших компьютерах можно использовать меньшую локальную модель. Настройка выбора инструментов сохраняется отдельно для компании.

Проверки: тесты ограниченного каталога, валидации, порога уточнения, выбора почтового навыка и единственного вызова обработчика; проверка обновления модели без потери предыдущего выбора при ошибке; полный набор тестов и Electron UI smoke. На установленной Qwen3:4B шесть запросов (баги, объяснение ANR, отрицание, сводка, веб, реальные ANR) выбрали ожидаемые инструменты. Это небольшая проверка маршрутизации, не гарантия точности на произвольной речи и не проверка реальных аккаунтов.
