# Разбор падений сборки из Slack

«Петя, почему билд падает в этом логе?» ищет материал в последних восьми наблюдавшихся обсуждениях приложения Slack. Наблюдение работает при включённом модуле Slack и работающем Пете, раз в пять секунд, только когда Slack — активное приложение. macOS требует разрешения «Универсальный доступ»; Windows использует UI Automation. В браузерном Slack наблюдение пока не работает.

Slack API не сообщает историю открытых тредов. История до запуска Пети недоступна. Наблюдатель читает доступный дереву доступности текст после заголовка Thread/Тред/Ветка/Обсуждение, не нажимает кнопки и не прокручивает окно. Если Slack не отдаёт заголовок или текст, нужно открыть тред/прокрутить к ошибке или приложить файл вручную. Виртуализированные и свёрнутые сообщения могут отсутствовать. На настоящем Slack обеих платформ чтение требует дополнительной проверки; автоматические тесты проверяют обработку снимков, не интерфейс Slack.

Выбирается самое недавно просмотренное обсуждение с ошибкой или логом. Сопоставление с API-контекстом идёт по доступной ссылке либо единственному совпадению полного сообщения/имени вложения. Для вложенных файлов без ссылки нужно предварительно обновить Slack (или включить его фоновое обновление). Неоднозначное совпадение не выбирается автоматически. Свежие ответы запрашиваются через conversations.replies; неполнота страницы сообщается. Без API доступен только видимый текст.

Текстовые вложения .log/.txt/.out/.json/.xml/.yaml/.yml/.csv: не больше трёх по 2 МБ. Нужен user token с files:read. Scope добавлен в исходники OAuth-сервера; уже развёрнутый сервер сам не обновляется, потребуется его обновить и переподключить аккаунт. Внешние файлы и HTTP-перенаправления не загружаются; Slack bearer передаётся только files.slack.com. Большие логи сокращаются вокруг строк ошибок, общий контекст ограничен 60 000 символов.

Модель только локальная Ollama. Ответ должен назвать строку ошибки, отделить предположения и предложить проверку. Недоступность лога явно сообщается, а не заменяется выдуманной причиной. Ответ и материалы сохраняются отдельной темой, допускают уточняющие вопросы. Голосовой вопрос озвучивается существующим механизмом диалога. Ссылка на тред показывается, когда её удалось установить. Снимки и темы хранятся зашифрованно по общему сроку 1–7 дней; «Очистить память» удаляет их.

Разговорные указания «Петя, посмотри эту фигню», «глянь вот это», «разбери эту штуку» тоже запускают разбор. Приоритет: ожидающие вложения → активная тема, обновлённая меньше десяти минут назад → последнее просмотренное обсуждение Slack не старше десяти минут. Для общего указания не требуется наличие ошибки в треде и не навязывается диагностика сборки. Если доступного свежего контекста нет, Петя просит показать материал. Такие обращения не создают задачи и не запускают исполнителей.
