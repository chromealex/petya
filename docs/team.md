# Команда

Отдельная вкладка «Команда» работает независимо от подключений Jira и Slack. Добавьте до 100 коллег: имя, привычные варианты имени, роль, проекты, обязанности, email и необязательные Slack member ID / Jira accountId. Изменения и удаление применяются после «Сохранить команду».

Прежнее поле Jira «Кто за что отвечает» доступно в дополнительных сведениях команды; его содержимое сохраняется без автоматического разбора. Карточки хранятся зашифрованными в настройках средствами ОС, дополнительные сведения сохраняются как прежние настройки. Команда не удаляется при очистке временного контекста.

Справочник передаётся локальной модели в диалоге и при подготовке/редактировании задач Jira. Имена добавляются в подсказку распознавания речи. При включённом разъяснении через Claude/Codex ограниченный фрагмент справочника может передаваться выбранному помощнику вместе с вопросом. Для больших команд контекст ограничен; совпадения с вопросом идут первыми.

Примеры: «Кто отвечает за Android?», «Чем занимается Полина?», «К кому идти с вопросом по релизу GAME?». Ответ формируется моделью по введённым сведениям. При нескольких кандидатах Петя должен уточнить проект или человека. Сведения о постоянной роли не подтверждают текущего исполнителя конкретной сборки. Добавление контакта само по себе не отправляет сообщений и не назначает задачи; существующие проверки доступных исполнителей Jira сохраняются. Автоматический выбор адресата вопроса о билде по-прежнему использует свежий тред Slack.
