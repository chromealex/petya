# Telegram — личный аккаунт

В выбранной компании откройте «Подключения», включите Telegram. Получите свои api_id и api_hash на https://my.telegram.org/apps (официальная инструкция: https://core.telegram.org/api/obtaining_api_id). Введите их и телефон в международном формате. Код и, при необходимости, пароль 2FA вводятся в Пете; они не сохраняются. Поддержаны запросы email/кода email при входе. Новый аккаунт Telegram приложение не создаёт; CAPTCHA не автоматизируется.

После входа нажмите «Показать чаты и каналы», отметьте нужные и сохраните выбор. Показаны первые 200 диалогов и ранее выбранные чаты; для контекста можно выбрать до 20. «Обновить контекст» читает последние 100 сообщений каждого выбранного чата за срок хранения 1–7 дней. Автообновление — каждые 5 минут, только для активной компании. Ограничения/частичные ошибки видны в статусе. Частота ручных запросов ограничена.

Сообщения сохраняются в общей зашифрованной памяти компании с автором, датой, ссылкой на сообщение канала и номером исходного сообщения для ответов. Они доступны во вкладке «Контекст», для подготовки задач и ответов локальной модели на вопросы о Telegram. Команды «обнови телеграм», «прочитай телеграм» и «проверь телеграм» сначала запускают обновление. Остальные вопросы используют сохранённые данные; в модель попадает ограниченный фрагмент последних пяти чатов. При синхронизации сохраняются сведения о фото и видео, включая сообщения без подписи. Само медиа скачивается только по запросу через выбор вложений в Пете. Голосовые и секретные чаты не поддерживаются. Код не отправляет сообщений и не отмечает историю прочитанной.

Одна Telegram-сессия на компанию; разные компании могут подключить разные аккаунты. API hash и сессия хранятся зашифрованными средствами ОС в профиле компании. UI не получает строку сессии. Отключение удаляет локальную сессию; ранее загруженный контекст остаётся до очистки/истечения срока. Активную сессию можно завершить в Telegram → Настройки → Устройства. Удалённая авторизация не отзывается автоматически.

MTProto-клиент teleproto 1.232.1 (https://docs.teleproto.dev/), bundled CJS через esbuild 0.28.2: src/vendor/telegram/client.cjs. Все необходимые JS/WASM встроены в файл, необязательные native websocket accelerators исключены. Лицензии — THIRD-PARTY-NOTICES.txt. Без пакетов npm на компьютере пользователя. Проверки входа, 2FA и импорта используют подставной клиент; реальный аккаунт пользователь подключает самостоятельно.
