# Telegram — personal account

In the selected company, open «Подключения» (Connections) and turn on Telegram. Get your api_id and api_hash at https://my.telegram.org/apps (official instructions: https://core.telegram.org/api/obtaining_api_id). Enter them and your phone number in international format. The code and, if needed, the 2FA password are entered in Petya; they are not saved. Email/email code requests during sign-in are supported. The app does not create a new Telegram account; CAPTCHA is not automated.

After signing in, press «Показать чаты и каналы» (Show chats and channels), check the ones you need and save the selection. The first 200 dialogs and previously selected chats are shown; up to 20 can be selected for context. «Обновить контекст» (Refresh context) reads the last 100 messages of each selected chat within a retention period of 1–7 days. Auto-refresh runs every 5 minutes, only for the active company. Limits/partial errors are visible in the status. The frequency of manual requests is limited.

Messages are saved in the company's shared encrypted memory with the author, date, a link to the channel message and the original message number for replies. They are available in the «Контекст» (Context) tab, for preparing tasks and for the local model's answers to questions about Telegram. The commands «обнови телеграм» (refresh Telegram), «прочитай телеграм» (read Telegram) and «проверь телеграм» (check Telegram) first start a refresh. Other questions use the saved data; a limited excerpt of the last five chats goes into the model. During sync, information about photos and videos is saved, including messages without a caption. The media itself is downloaded only on request through attachment selection in Petya. Voice messages and secret chats are not supported. The code does not send messages and does not mark history as read.

One Telegram session per company; different companies can connect different accounts. The API hash and session are stored encrypted with OS facilities in the company profile. The UI does not receive the session string. Disconnecting deletes the local session; previously loaded context remains until it is cleared/expires. An active session can be terminated in Telegram → Настройки → Устройства (Settings → Devices). The remote authorization is not revoked automatically.

MTProto client teleproto 1.232.1 (https://docs.teleproto.dev/), bundled as CJS via esbuild 0.28.2: src/vendor/telegram/client.cjs. All required JS/WASM are embedded in the file; optional native websocket accelerators are excluded. Licenses — THIRD-PARTY-NOTICES.txt. No npm packages on the user's computer. Sign-in, 2FA and import checks use a mock client; the user connects a real account themselves.
