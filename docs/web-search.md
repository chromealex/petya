# Search in the built-in browser

Turn on «Поиск в интернете» (Internet search) in connections. Commands: «Найди в интернете, как настроить …» (Find on the internet how to set up …), «Посмотри в гугле …» (Look up on Google …), «Загугли …» (Google …). Petya opens Google in its own Chromium window on the user's computer. No API keys or separate search service are needed.

Search is started explicitly. In a separate search topic, follow-ups such as «А для Windows?» (And for Windows?) and «Покажи другой способ» (Show another way) are available. The query includes only the previous search query of this topic and the new utterance, without the history of mail, Jira or other work topics. Explicit email addresses, some key formats and links with parameters are rejected; this is not a universal privacy detector — do not include secrets or personal information in the search phrase.

If Google requires a CAPTCHA, consent or sign-in, complete the action in Petya's window, return to the results and press «Продолжить поиск» (Continue search) in the dialog or say this command. Checks are not bypassed automatically. Google receives the search queries, as with normal browser use. The Google session is stored in a separate Petya profile.

Petya chooses up to five links from the result titles, tries to read up to three pages through separate Chromium windows and passes the text to the local Ollama. Public pages are read without the Google session cookies. The first 10000 characters of visible text are taken from each source. Search results and pages may change their structure or deny access; if no pages are read, Petya shows the links without claiming that the answer has been verified. If the model fails, the links also remain. Source numbers in the answer are tied to the pages actually read; the content of the answer requires the usual critical review.

The browser has no Node.js or preload with access to Petya's API, and uses sandbox and context isolation. Pop-up windows, file downloads, microphone and other permissions are disabled. Keys of other connections are not passed to the browser. Turning the module off closes its windows. PDF, restricted sections and some dynamic pages are not supported. There is no automatic search over arbitrary conversations yet.

Checks: routing of explicit requests and follow-ups, negations, blocking of obvious secrets in a query, link filtering, source numbering, reading and model errors, returning after a Google check; the full test suite and UI smoke. A real Chromium read the Electron documentation; Google in the test profile required a manual continuation, so a full live search without this step has not been confirmed.
