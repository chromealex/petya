Проекты Jira

Подключите Jira, чтобы выбрать проекты.

Отметьте проекты, с которыми может работать Петя. Проект для каждой задачи определяется по команде и контексту обсуждения. Если данных недостаточно, Петя уточнит выбор.

Поиск документации использует Confluence на том же сайте и Atlassian API token. Нужен доступ к страницам. Текущая версия выбирается автоматически только при однозначности или заданном ID.

Если проект требует дополнительные поля, создание вернёт ошибку. Их поддержку добавим отдельно.
