Claude и Codex

Новый чат в установленном приложении, с задачами и контекстом обсуждения.

История действий

Задачи, правки и откаты — с результатом каждого шага.

Последние 100 записей хранятся на этом компьютере. Содержимое и снимки для отката доступны в пределах выбранного срока хранения. Перед применением Петя сверит состояние задач с Jira.

Компании

У каждой компании свои команда, подключения, диалоги, задачи, обучение и напоминания.

При переключении Петя перезапустится. Фоновые проверки и напоминания работают только в выбранной компании. Уже переданная Claude/Codex работа продолжается в их приложениях.

Записывайте разговоры и добавляйте материалы в профиль соответствующей компании. Новая компания получает только настройки локальной модели и распознавания речи; рабочие подключения настройте отдельно.

Затем выберите компанию в переключателе слева.

Команда

С кем вы работаете и кто за что отвечает. Петя использует эти сведения в диалоге и при подготовке задач.

Например: «Кто отвечает за Android?» или «Чем занимается Полина?». Укажите проекты и привычные имена. Контакты необязательны; их добавление само по себе не отправляет сообщения.

Сведения сохраняются до изменения или удаления вами и не очищаются вместе с историей диалога.

Подключения

Подключения выбранной компании

Аккаунты, токены, проекты, каналы и включённые модули сохраняются отдельно для каждой компании. Выберите компанию слева, затем подключите её сервисы здесь.

Slack, Jira/Confluence, Asana, Notion, Gmail и Google Play можно подключить к разным рабочим аккаунтам. В каждой компании доступен свой список аккаунтов Gmail. При входе через внешний браузер выбирайте аккаунт нужной компании.

Claude и Codex используют текущий вход в установленных приложениях. Петя пока не переключает их аккаунты автоматически. При необходимости смените аккаунт в самом Claude/Codex перед передачей работы.

Подключите нужные сервисы и проверьте доступ. Секреты сохраняются средствами вашей ОС.

    ПАМЯТЬ И ФОНОВАЯ РАБОТА

    Контекст на неделю

    Расшифровки, Slack и заметки сохраняются зашифрованными на этом компьютере, переживают перезапуск и автоматически удаляются по сроку. Аудиофайлы не сохраняются. Запросы агентов и локальные снимки Jira для отката также очищаются по сроку; отправленные данные в Jira / Claude / Codex остаются в этих сервисах.

    Чтение идёт через API и работает, даже если окно Slack закрыто. Обновляется история корневых сообщений за срок хранения и их доступные треды. Запросы могут ждать лимита Slack.

    Петя автоматически обнаруживает встречу Zoom, расшифровывает разговор и сохраняет его в контекст для ваших команд. Выбирать окно не нужно. После окончания встречи расшифровка останавливается примерно через 15 секунд. Захватывается весь системный звук; аудио и видео не сохраняются. Потребуются разрешения ОС. Остановка из трея приостанавливает автозапуск до следующей встречи.

    КОНТЕКСТ

    Slack

    * — все доступные неархивные каналы; jw-* — по префиксу. Для названий и масок нужны channels:read / groups:read. Личные переписки добавляются по ID. Нужен user token с channels:history / groups:history / im:history / mpim:history и доступом к выбранным перепискам. Для текстовых вложений нужен files:read. Для «что с билдом» — chat:write, im:write и users:read: Петя пишет ответственному или в канал обсуждения и ждёт ответ. При включённом модуле Петя запоминает видимый тред в активном приложении Slack: можно спросить «почему билд падает в этом логе». На macOS нужен Универсальный доступ. История просмотров начинается после запуска Пети; Slack в браузере пока не поддерживается. Личные переписки имеют ID D…. Учитываются лимиты Slack; первичная загрузка недели и тредов может занять время.

    ДОКУМЕНТАЦИЯ

    Notion

    Как подключить Notion

    1. Создайте подключение. Нажмите «Создать подключение в Notion» выше. В Notion выберите New connection / New integration, назовите его «Петя» и выберите рабочее пространство с вашей документацией. Тип — Internal (внутреннее).
    2. Разрешите чтение. В Capabilities (права доступа) включите Read content и сохраните.
    3. Скопируйте токен. В настройках созданного подключения найдите Internal Integration Secret / Internal connection token, нажмите Show, затем Copy. Вставьте скопированное значение в поле ниже.
    4. Дайте доступ к страницам. Откройте нужную страницу в Notion → ••• → Connections → Add connections → выберите «Петя». Повторите для нужных разделов документации.
    5. Проверьте подключение. Вернитесь сюда и нажмите «Сохранить и проверить». Петя проверит токен и наличие доступных страниц.

    Нет кнопки создания или нужного рабочего пространства? Попросите владельца рабочего пространства создать внутреннее подключение.

    Петя ищет по названиям страниц, доступных подключению. Содержимое документа добавляется в контекст после вашего выбора.

    Проекты Jira

    Подключите Jira, чтобы выбрать проекты.

    Отметьте проекты, с которыми может работать Петя. Проект для каждой задачи определяется по команде и контексту обсуждения. Если данных недостаточно, Петя уточнит выбор.
